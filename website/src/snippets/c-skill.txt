# sdlc-code-review

Review someone else's change as an independent engineer: verify claims instead of
trusting them, report what could not be verified, and never touch the code.

- Runs in the sdlc-code-review-agent (/sf-sdlc:review): a separate context that never
  saw the build, with read-only tools.
- Read-only: the only file written is the report (review.md).
