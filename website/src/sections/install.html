Install for Claude Code

Pick one form per project. Using both makes every agent and command appear twice.

# in Claude Code, on macOS, Linux or Windows
/plugin marketplace add nagarroARBsf/Sf-skills-agents
/plugin install sf-sdlc@nagarro-sf
/sf-sdlc:setup

Commands are namespaced /sf-sdlc:<name>. The CLI is on the PATH as sf-sdlc. To try the downloaded zip instead, unzip it and start claude --plugin-dir ./sf-sdlc.

# from the root of your Salesforce DX project
unzip ~/Downloads/claude-folder.zip -d .
# or, from a clone of the repository:
# cp -r /path/to/Sf-skills-agents/.claude ./.claude
claude
/sdlc-setup
# PowerShell, from the root of your Salesforce DX project
Expand-Archive "$HOME\Downloads\claude-folder.zip" -DestinationPath .
# or, from a clone of the repository:
# Copy-Item -Recurse C:\path\to\Sf-skills-agents\.claude .\.claude
claude
/sdlc-setup

Lifecycle commands are /sdlc-<name> and build-phase commands are /sdd-<name>. The CLI is node .claude/bin/sf-sdlc.
