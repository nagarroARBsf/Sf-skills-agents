Open to everyone

Want to contribute?

SF-SDLC is evolving, and the best improvements come from people using it on real Salesforce work. Whether you are at Nagarro or anywhere else, a fix, a new rule, a better template or a report of what broke in your sandbox all help.

1

Clone the repository

No write access? Fork it on GitHub first and clone your fork.

git clone https://github.com/nagarroARBsf/Sf-skills-agents.git
2

Make your change on a branch

Edit .claude/, the single source of truth. The plugin in plugins/sf-sdlc/ is generated from it.

git checkout -b my-change
3

Run the checks

Regenerate the plugin, then run the tests. Both must pass.

python3 scripts/build-claude-plugin.py
node --test tests/kit.test.js
4

Raise a pull request against main

Say what you changed and why. We review every contribution and merge it into main.

gh pr create --base main

Where help counts most

  • Real-project feedback: run a stage in a sandbox and report what worked and what broke.
  • Rules and checks: a Salesforce mistake the agents keep making, turned into a rule or a Code Analyzer check.
  • Templates: BRD, story, design and test templates your teams already use.
  • Docs: anything on this site or in SETUP.md that was unclear.
