By role

Business analyst / product owner

No Salesforce CLI or org needed.

  • brd, stories, test-cases, trace
  • /output-style → Salesforce Business Analyst for requirements and stories in business language
  • Your own Jira process and templates; Jira CSV when Jira is not connected

Manager / sponsor

The high-level picture.

  • trace for status and what is blocked
  • /output-style → Salesforce Manager: status, risks and decisions needed, no technical detail
  • Release readiness and go/no-go from release

Developer / architect

Spec first, tests first.

  • specify → plan → tasks → implement → verify
  • /output-style → Salesforce Developer for terse, evidence-led answers
  • Plan mode follows the same 12-section plan format
  • sf-sdlc check and analyze before committing

Release engineer / QA

Validate before deploying.

  • deploy <org> and release can only be started by a person
  • test-run, ui-test, retest; monitors report job completion
  • Workflow sdlc-release-readiness gathers evidence in parallel
