Known limitations

Beta The SF-SDLC Framework is in beta. It has not yet been tested on real customer projects. Try it in a sandbox and on non-critical work first, and tell us what you find.

  • Not yet run end to end on a real project. The deploy, test-run and Jira paths have not been exercised against a real org or Jira project. Prove them in a sandbox before relying on them.
  • The framework is still evolving. Commands, skills, file layouts and config keys can change between releases. You can help shape it: contribute.
  • 3.0 is new: moving seven stages from agents into skills, browser UI testing, project templates and the rewritten rules are covered by structural unit tests, not yet by a customer project. The rules cite Salesforce documentation as of Winter '27; check them against your org's API version.
  • Monitors and themes are experimental in Claude Code and may need changes when their format moves. Monitors do not run in headless (claude -p) sessions.

The full list is in the README.
