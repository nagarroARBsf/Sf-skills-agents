Traceability runs through one ID chain: BR-04 → FR-04.2 → US-04-02 → LLD-US-04-02 → TC-US-04-02-007 → TR-… → DEF-012 → DEP-005 → REL-1.4.0. /sf-sdlc:trace shows it at any time.

Every repeated mistake becomes a constraint. Instructions and skills are advisory; tests, Code Analyzer rules, hooks and quality gates are deterministic. A defect closes only when its record names the constraint added (or says why none fits), and the reviewer recommends the strongest check that would have caught a finding.
