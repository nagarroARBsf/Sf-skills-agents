This framework is inspired by Salesforce's Accelerate Agent-Driven Development with the Headless Toolkit (Mohith Shrivastava, Salesforce Developers Blog, 10 November 2026). The post describes a seven-stage loop of ground, specify, build, verify, review, release and observe. SF-SDLC turns that loop into skills, commands, five agents and guard hooks for Claude Code, and adds the requirements, architecture, testing and release stages a delivery team also needs.

How the kit maps to the Headless Toolkit loop

Headless Toolkit stageIn SF-SDLC
1. GroundSetup skill, ontology.yaml and feature map, Metadata Grounding MCP server
2. SpecifyBRD, stories and architecture stages, then the /sdd-* spec, plan and tasks commands
3. BuildMain conversation, one approved task at a time, following the spec-driven skill, the coding rules and the Salesforce skills installed for the project
4. VerifyCode Analyzer through /sdlc-analyze, Apex and Jest runs through /sdlc-test-run, hooks that run on every edit
5. ReviewRead-only code reviewer agent, in its own context: Code Analyzer plus the Salesforce coding rules, every finding citing file and line; the sdlc-review-changes workflow for a parallel pass
6. ReleaseDeploy and release skill, started by a person: validate, then quick deploy; the production gate stays with a person
7. ObserveObserve stage; findings become new specs and new checks
