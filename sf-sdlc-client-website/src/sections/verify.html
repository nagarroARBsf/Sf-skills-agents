sf-sdlc doctor            # every required line should show ✔
sf-sdlc config validate
sf-sdlc org classify      # your production org must report "production"
sf-sdlc analyze --changed # the official Code Analyzer runs, with your custom rules
sf-sdlc mcp status        # hosted MCP servers: connected with their tools, or why not

Copy-in folder: prefix each with node .claude/bin/. Or run /sf-sdlc:doctor.

Upgrading from 2.x? Plugin users get 3.0 with /plugin update. With the copy-in folder, copy the new .claude/ over the old one, then run sf-sdlc doctor: it lists the files 2.x left behind (the seven removed agents, the old output styles, the renamed setup skill) for you to delete.
